# 打磨记录 · DSH 配色预览（浅色 + 深色）

交付物：`design-demos/palettes-preview.html`；整页截图 `design-demos/overview-light.png` / `overview-dark.png`。

## 第 1 轮（浅色首版）

最伤的三处：主窗口比下面几栏窄 260px（舞台两列挤压）；浅色色卡在页面底色上几乎看不见；
小字灰阶只有 2.9:1。→ 方案栏改成横向索引、色卡加内描边、全局灰阶重定（#6A6C70 弱化 / #5F6165 正文灰）。

顺带修掉：聊天标题与 748px 正文列没对齐；设置行控件离面板右缘差 180px。

## 第 2 轮（浅色复核）

最伤的三处：标题仍偏左 18px；强调色在窗内几乎看不见（五套只剩画布色差）；
侧栏 4 条会话下留了 300px 空白。→ 标题栏套 748px 容器、助手段落加真实链接、补两条会话；
设置面板的配色选择器改成「画布 / 侧栏 / 气泡」三段竖切 + 强调色底线。

## 第 3 轮（浅色收尾）

1024px 窄窗无横向溢出；五套截图逐张看过；对比度脚本全绿：正文 16.3–17.0:1，
次要 ≥6.8:1，说明 ≥4.8:1，气泡内正文 ≥14.9:1。

## 第 4 轮（深色适配，2026-11-12）

最伤的三处：

1. **深色不能只把浅色反相**。第一版暗面色是「深底 + 同一支强调色」，强调色落在强调底上只有
   3.8–4.4:1，按钮文字、说明文字也在边缘。→ 每套重定画布 / 侧栏 / 卡片 / 气泡四层暗面，
   强调色提亮一档，校验脚本加暗色下限（正文 ≥12、次要 ≥8、强调底 ≥4.5、按钮文字 ≥4.5）。
2. **五套缩略图在深色下几乎一个颜色**。→ 暗面加入同色相的色相偏移（棕 / 蓝 / 橄榄 / 紫 / 青），
   明度阶梯保持在 5.6–7.6 L*，缩略图能一眼分开。
3. **页面的「约束」只写了浅色数字**，切到深色会自相矛盾（「气泡里 ≥15:1」在深色不成立）。
   → 改成双模式区间；设置里的「外观」控件接上预览模式，点深色会同步切主预览。

## 第 5 轮（收尾复核）

- 对比度：浅色正文 16.3–17.0:1、深色 15.6–16.1:1；次要 ≥6.8；说明 ≥4.8；气泡内正文 ≥13.5。
- 强调色在强调底上 4.5–6.3；主按钮文字 15.9–18.5。
- 浅色 / 深色各自的整页截图都逐屏看过；深色窗口阴影、边框与页面底色的关系单独调过。

## 已知限制

- 窗体和设置面板是**结构示意**：布局按 DSH 的 748px 内容列、268px 侧栏、14/22 正文行高搭的，
  组件细节不是逐像素还原。颜色值来自 `palettes.json`，是插件实际写入的 token。
- `--dsw-alias-illustration-*`（空白会话插画）、diff / shiki 语法色没有跟着换，留给后续。
