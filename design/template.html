配色方案预览
给 DSH 做几套浅色配色，先在 HTML 里看看效果，选定后再做成插件。别影响文字的可读性。

先做五版，只改画布、侧栏、气泡和强调色四个维度，其余沿用同一套 alias token，可对照 token 表。深色外观保持原样，切换入口放在「设置 → 通用」。

每套都过一遍对比度：正文 15:1 以上，次要文字 6:1 以上，说明文字也不低于 4.5:1。

约束

  • 文字对比度：正文浅色 16.3–17.0:1、深色 15.6–16.1:1；次要 ≥6.8:1；说明文字 ≥4.8:1；气泡里的正文 ≥13.5:1。
  • 气泡与画布：明度差浅色 3.3–4.2 L*、深色 5.6–7.6 L*，一眼能分出消息与底，又不喧宾夺主。
  • 强调色：只用于链接、选中行、焦点环与代码里的关键行；成功 / 警告 / 错误沿用 DSH 语义色，不跟着方案走。
  • 结构：边框仍是 7%–25% 的四级 hairline，圆角、字号、间距一律不动。
