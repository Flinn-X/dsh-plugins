# 方向确认

- 展示物：`design-demos/palettes-preview.html`（五套浅色方案、可切换主界面、设置入口示意、并排对比、token 表）。
- 用户原话：**「就这样，试试吧」**（2026-11-11，看过整页之后）。
- 采用的理解：不再是「五选一」，而是**整套交付**——五套全部装进一个插件，首次运行默认套用「纸白」，随时可在 设置 → 通用 → 配色方案 里切换，或点「默认」回到 DSH 原样。
- 范围：只覆盖浅色外观；深色外观保持 DSH 默认，切换时自动暂停配色层。
- 装配位置：`settings.general.item`，order `10.5`，落在「外观」与「字号」之间。

## 实装与预览的差异（有意为之）

- 真实的设置行是**标题在上、色卡在下**（与 DSH 自带「外观」行同构），预览里画的是左右两栏；同一行的文案、六个色卡（默认 + 五套）与选中描边一致。
- 预览里没有画「恢复默认」之外的额外开关；实装里点「默认」即等于恢复。
- 配色以 `ctx.theme.overrideTokens` 叠加 token 层；若主题服务拒绝该层，插件退回 `body:not([data-ds-dark-theme])` 作用域的样式表，视觉结果一致。


## 2026-11-12 扩展：深色适配

- 用户原话：**「扩展一下这个插件，新增对深色模式的适配。」**
- 结论：五套各补一套深色 token（仍是同一组 42 个语义槽位），浅色 / 深色随 DSH「外观」自动切换，不再暂停。
- 预览页增加「浅色 / 深色」切换、深色对比度与深色截图；设置里的「外观」控件与预览模式联动。
